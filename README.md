# 🎮 GAMEZONE **Your ultimate destination for next-gen gaming reviews, esports coverage, and library management.**    [](LICENSE)
--- ## 🌟 Overview **GAMEZONE** is a modern web application tailored for gamers to discover, track, and manage their favorite and purchased video games. Built with **Next.js**, **React**, and **Tailwind CSS**, it features a dark neon/cyberpunk aesthetic, glassmorphic UI elements, smooth responsive layouts, and interactive state management. --- ## ✨ Key Features * 🎮 **Extensive Game Library**: Browse a collection of top-tier AAA and indie titles (GTA VI, Call of Duty: Black Ops 6, EA Sports FC 26, Elden Ring, and more). * ❤️ **Favorites Management**: Easily add or remove games from your personal favorites list with dynamic feedback. * 🛍️ **Purchased Games Tracker**: Track your owned games, display total playtime hours, and manage purchase history with verified badges. * 🌌 **Cyberpunk & Glassmorphism UI**: Custom dark theme styled with glowing neon accents, smooth transitions, and hover animations. * 📱 **Fully Responsive Layout**: Mobile-first design that scales seamlessly across smartphones, tablets, and desktop displays. * ⚡ **Global State Management**: Powered by React Context API (`GameContext`) for seamless data synchronization across all views. * 🔔 **Instant Toast Notifications**: Real-time action feedback powered by `react-toastify`. --- ## 🚀 Getting Started Follow these instructions to get a local copy of the project up and running. ### Prerequisites Ensure you have the following installed on your system: * **Node.js**: `v18.0.0` or higher * **npm**, **yarn**, or **pnpm** ### Installation 1. **Clone the repository** ```bash git clone https://github.com/your-username/gamezone.git cd gamezone ``` 2. **Install dependencies** ```bash npm install # or yarn install ``` 3. **Run the development server** ```bash npm run dev # or yarn dev ``` 4. **Open in browser** Navigate to http://localhost:3000 in your browser to see the application. --- ## 🎨 UI Components Overview * **`ListCard`**: Full-width glassmorphic card displaying game info, star rating, price, category tag, and an instant remove button. * **`PurchesListCard`**: Emerald-themed card featuring verified purchase checkmarks, playtime counters, and a delete action. * **`RootLayout`**: Enforces full-height flexbox structure (`flex flex-col min-h-full`) to guarantee the footer remains fixed at the bottom. --- ##
